## Product name

Magpie Library

## Short description

A calm, minimal library for your design references. Drop in images, fonts, PDFs and links, and keep them sorted into folders.

## Description

Magpie is a home for everything that inspires your work: poster layouts, patterns, 3D renders, type specimens, UI screenshots, fonts, PDFs, links and notes.

Paste, drop or add anything, and choose its folder. Or turn on auto-sorting: Magpie looks at each new item and files it for you, creating new folders as your collection grows.

Everything stays on your computer. Your library is an ordinary folder in Documents, with a real subfolder for each category, so you can browse it in File Explorer, back it up, or keep it in OneDrive. No account, no subscription and no upload limit. The only limit is your disk.

• A quiet, minimal interface that puts your references first
• Paste (Ctrl + V) or drag images straight from your browser
• Fonts get their own folder, arranged by type, with a live preview you can type into
• Search everything by title, tag, folder or colour
• See each image's colour palette and copy any colour's hex code
• Light and dark mode

Auto-sorting is optional and uses your own Anthropic API key. Without it, you pick the folder yourself.

## What's new in this version

Magpie (formerly Design Library) now has light and dark mode, and a Fonts folder with subfolders for each type of font.
